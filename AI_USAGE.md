# AI usage

Afterimage Protocol used an AI coding assistant to explore product directions, inspect the QoreChain Developer Fest requirements, and produce the initial interface implementation.

The human team chose the product direction, name, release model and intended user experience. The current prototype is reviewed by the team and labels its simulated guardian action clearly. Before submission, the team will document the implementation of each cryptographic and on-chain component, along with human review of its security boundaries.
